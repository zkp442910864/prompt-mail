# 2026-05-06

## 修复翻译后样式布局丢失
- **根因**：后端 `translateToChinese` 把完整 HTML 发给 AI，但 system prompt 只说"翻译为中文"，AI 返回纯文本丢弃了 HTML 结构；前端再用 `marked.parse()` 处理进一步破坏布局
- **后端 `aiService.ts` 修改**：
  - 检测 body 是否包含 HTML 标签
  - HTML 邮件使用专用 prompt：要求保持原有 HTML 结构不变（表格/div/span 嵌套、style/class 属性），只翻译标签间文字
  - 纯文本邮件保持原 prompt 不变
  - 清理 AI 可能包裹的 ` ```html ``` ` 代码块标记
- **前端 `MailDetailPanel` 修改**：
  - 移除 `marked` 导入，不再对翻译结果做 Markdown→HTML 转换
  - 新增 `isTranslatedHtml` 判断（useMemo，检测翻译结果是否含 HTML 标签）
  - HTML 翻译结果：`sanitizeHtml()` 后直接 `dangerouslySetInnerHTML` 渲染（和原文一样走 mail-body 样式）
  - 纯文本翻译结果：`whitespace-pre-wrap` 直接显示
