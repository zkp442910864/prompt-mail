## 邮件详情 URL 参数化
- **需求**：选择邮件后 URL 带上 `mailId`，刷新/直接访问该 URL 自动展示对应邮件
- **`App.tsx`**: 新增 `/inbox/:mailId` 路由（HashRouter 下 URL 如 `#/inbox/123`）
- **`InboxPage`**: 作为 URL ↔ Context 双向桥梁
  - `useParams<{ mailId }>()` 读取 URL 参数
  - `useEffect` 监听 `mailId` 变化 → `dispatch(SET_SELECTED_MAIL)` 同步到 MailContext（URL → Context）
  - `handleSelectMail(id)` → `navigate(/inbox/${id})` 更新 URL（Context → URL）
- **`MailListPanel`**: 新增 `onSelectMail` prop，点击时调用回调（不再直接 dispatch context）
