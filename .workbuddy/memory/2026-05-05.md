# 2026-05-05

## Bug 修复
- **Bug1: 刷新页面后选择的邮箱丢失** — `currentEmailConfigId` 从 React state 迁移到 localStorage 持久化 (key: `prompt-mail-current-email-config-id`)
- **Bug2: 邮件列表 500 "Command failed"** — 根因是 IMAP 认证失败(authCode是初始默认值"your-auth-code")，错误信息透传优化
  - `imapService.createImapClient`: port 改为 `Number(config.imapPort)` 防御字符串类型
  - `emailConfigController`: `imapPort`/`smtpPort` 强制 `Number()` 转换
  - `mailController`: 错误透传 `authenticationFailed` → "邮箱认证失败" 友好提示
  - `smtpService`: port 同样加 `Number()` 防御
- **AppHeader 邮箱类型标签** — 从只支持 aliyun/qq 扩展为4种: 阿里个人/阿里企业/QQ/自定义

## UI 优化
- **邮件列表视觉区分** — 未读邮件: 蓝色圆点 + 加粗 + 左边框高亮; 已读: 灰色常规
- **邮件倒序排列** — `fetchMailList` 结果按 date 倒序 sort
- **回复窗口改为悬浮小窗** — MailReplyEditor 重写为可拖动/最小化/最大化的浮动面板
- **AI 生成结果弹窗** — 新建 AiResultModal，双 Tab(邮件语言/中文对照)，支持直接复制
- **Gmail 风格邮件列表改版** — MailListItem 重构为单行紧凑布局: 星标 + 发件人 | 主题—摘要 | 日期+附件，h-11行高，选中蓝底(#c2dbff)，悬停灰底，未读加粗；虚拟列表行高从72→44
- **邮件排序 Bug 修复** — 改用 UID 倒序替代 envelope.date 倒序，因为信封日期不可靠（时区/声明值问题）；UID 递增且反映邮件到达顺序
- **分割线加深** — border-gray-100 → border-gray-200，提升视觉清晰度
- **border-gray Bug 修复** — 多个文件误用 `border-gray-20`（无效色值），全部修正为 `border-gray-200`；AppLayout 的 Ant Design Header 用包裹 div 隔离 CSS-in-JS 覆盖
- **UnoCSS 预设升级** — `presetWind` → `presetWind4`（Tailwind v4 兼容），启用内置 CSS reset（preflights.reset: true），安装 `@unocss/preset-wind4`

## UI 改进（第二轮）
- **配置页面精简为单条模式** — 后端 aiConfigStore/emailConfigStore 的 `save()` 改为"已有则更新，否则新建"逻辑，不再 append 多条；前端去掉多余的 configId state
- **移除邮件列表收藏按钮** — MailListItem 删除 star 按钮及相关 state/handler/imports (StarOutlined, StarFilled)
- **添加拖拽附件上传** — MailReplyEditor 新增 Ant Design Upload.Dragger 附件区域，点击📎按钮显示拖拽上传区域，附件列表显示在编辑区下方
- **AI 配置提示词替换为富文本** — AiConfigCard 的 systemPrompt 从 Input.TextArea 替换为 TipTap 富文本编辑器（带加粗/斜体/代码/列表工具栏）
- **AI 结果弹窗替换为富文本展示** — AiResultModal 的"邮件语言"和"中文对照"两个 Tab 内容从 plain text (whitespace-pre-wrap) 替换为 TipTap 只读编辑器渲染，支持 HTML 富文本展示
- **新增 CSS 样式** — editor.css 新增 `.tiptap-prompt-editor` 和 `.tiptap-readonly-editor` 样式
- **Markdown→HTML 渲染修复** — 安装 `marked` 库，AI 生成内容（Markdown 格式）通过 `marked.parse()` 转 HTML 后再传入 TipTap 编辑器渲染，修复格式丢失问题（如 `**加粗**` 不渲染）
- **回复编辑器填入 AI 内容时也转 HTML** — `handleUseContent` 中对 Markdown 内容调用 `marked.parse()` 后再 `editor.commands.setContent(html)`
