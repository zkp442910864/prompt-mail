# 2026-05-31

## 修复回复邮件地址提取逻辑
- **问题**: `extractReplyToEmail` 对所有邮件都从正文提取邮箱，导致回复普通邮件时选错收件人（如 CC 的人）
- **修复 `emailExtractor.ts`**:
  - 非系统邮箱 → 直接使用 `from.address`（这就是客户本人）
  - 系统邮箱 → 从正文提取客户邮箱
  - 不再过滤 `fromAddress` 自身，因为系统邮件场景下 fromAddress 已经是系统地址
- **新增 `MailDetail.replyTo` 字段**:
  - 前端 `types/mail.ts`、后端 `server/types/index.ts` 新增 `replyTo: EmailAddress[]`
  - `imapService.fetchMailDetail` 解析 mailparser 的 `parsed.replyTo`
- **`MailReplyEditor` 回复地址优先级**:
  1. `detail.replyTo` 头（邮件标准回复地址，最权威）
  2. `extractReplyToEmail` 正文提取逻辑
  3. `from` 地址兜底
- **`bodyEmails` 候选列表改进**: 系统邮件只列非系统邮箱，普通邮件列出所有邮箱包括 from 地址
