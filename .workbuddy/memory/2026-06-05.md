# 2026-06-05

## 修复 AI 生成回复时图片资源导致报错
- **问题**: 邮件 HTML body 中包含 base64 图片（可能几 MB），远超 AI API token 限制，导致请求失败
- **修复 `server/services/aiService.ts`**:
  - 新增 `stripHtmlForAI()`: 移除 `<img>` 标签（base64 来源）、`<style>`/`<script>` 块、HTML 注释、行内 data URI
  - 新增 `htmlToPlainText()`: HTML 转纯文本兜底（保留换行结构，解码 HTML 实体）
  - 新增 `prepareBody()`: 流水线处理 — 检测 HTML → stripHtml → 超 8000 字符转纯文本 → 硬截断
  - `generateReply` 和 `translateToChinese` 均使用 `prepareBody(data.body)` 替代原始 `data.body`
